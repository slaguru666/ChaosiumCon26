# Asset Library

System reference files for all game systems used at Chaosium Con 2026.
Each folder contains a REFERENCE.md with characteristics, skill rolls, combat, stat block formats, and setting notes.

| Folder | System | Publisher | Edition |
|--------|--------|-----------|---------|
| `coc-7e/` | Call of Cthulhu | Chaosium | 7th Edition |
| `brp-modern/` | Basic Role-Playing | Chaosium | Modern Edition |
| `stormbringer-1e/` | Stormbringer | Chaosium | 1st Edition |
| `ringworld-1984/` | Ringworld | Chaosium | 1984 (1st Edition) |

These references are used to:
- Write accurate NPC stat blocks in scenario documents
- Generate correct mechanic call-outs in scenario text
- Power the mechanics quick-reference panel in the GM companion app
