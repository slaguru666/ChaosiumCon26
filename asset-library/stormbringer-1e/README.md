# Stormbringer — Asset Library

Reference materials for running **Stormbringer** (1st–5th edition) and the French *Stormbringer* (Oriflam, 1984) in the Young Kingdoms setting.

---

## Files

| File | Description |
|------|-------------|
| `stormbringer_reference.html` | **Full interactive rules reference** — all 18 sections, searchable, dark-themed. Built from the French Oriflam edition source (1984). Open in any browser. |
| `REFERENCE.md` | Compact rules cheat sheet for the Chaosium English editions (BRP mechanics, Allegiance system). |

---

## Edition Notes

These two files cover different editions of the same game:

- **`stormbringer_reference.html`** is based on the **French Oriflam 1984 edition** — percentile BRP core, French terminology translated to English, with full nationality and social origin tables, the complete 50-entry major wounds table, sorcery, elementals, demons, cults, sanity, and creature stat blocks.
- **`REFERENCE.md`** covers the **Chaosium English editions (1e–5e)** — Strike Rank, Allegiance points, the standard BRP skill list. Use this for the Chaosium boxed sets.

Both editions share the same core BRP DNA (roll D100 equal-or-under skill) but differ in terminology and some mechanical details.
