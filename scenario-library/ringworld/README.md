# Ringworld RPG — Scenario Library

Scenarios using the **Ringworld RPG** (Chaosium, 1984), set in Larry Niven's Known Space universe.

---

## About Ringworld

Set in the far future (~2850 AD), the Ringworld is an artificial ring 1 million miles wide and 600 million miles in circumference orbiting a star. Players typically take the role of explorers — human or alien — uncovering its secrets.

Key species: Human, Kzinti, Puppeteer, Outsider, Pak, Ringworld hominids.
