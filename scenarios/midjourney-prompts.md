**Art Direction:** High-contrast ink sketch and pencil illustration. Rain-slicked cyberpunk noir. Blade Runner atmosphere collapsing into biological dread. Neon-lit black, deep shadow, organic warmth intruding into cold steel.

## USAGE NOTES

- All `--ar` values can be adjusted to suit Midjourney's current interface
- `--style raw` reduces Midjourney's default aesthetic processing — remove if you prefer more polish
- For NPC portraits: try `--ar 2:3` for vertical card format
- For location hero art: `--ar 16:9` for widescreen, `--ar 3:2` for print
- Add `--v 6` or `--v 6.1` for the latest Midjourney model if not set as default
- Paste prompts directly into `/imagine` in Midjourney Discord or the web interface
- For physical handout props (telegram, newspaper, codex): `--ar 3:4` prints well on A5
