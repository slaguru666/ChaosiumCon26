## Art Direction Notes
- Style: ink sketch + pencil illustration
- Palette: monochrome (black ink on off-white paper)
- Technology: precise linework, geometric, functional
- Organic/human: gestural, slightly looser strokes
- Scale: always emphasise vastness; human figures are tiny
- Era: 1984 science fiction — angular ships, clean scrith architecture, no sleek curves
